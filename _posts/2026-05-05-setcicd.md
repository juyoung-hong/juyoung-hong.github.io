# CI/CD 전용 VM 생성

<br>

Jenkins를 설치하여 소스코드에 변경사항이 발생했을때 docker 이미지를 빌드하고 OKE에 반영하는 등 일련의 작업을 수행할 CI/CD 전용 VM을 새로 생성합니다.

- 아래 글과 같이 CI/CD에 사용할 Subnet을 하나 더 구성합니다.
  - 오라클 클라우드로 무료 인프라 네트워크 구성하기: [링크](https://juyoung-hong.github.io/infra/ocinetwork/)
- 이후 아래 글에서 Bastion 서버를 만든 것처럼 Always Free shape으로 Compute Instance를 1개 더 생성합니다.
  - 오라클 클라우드에 무료 bastion 서버 구성하기: [링크](https://juyoung-hong.github.io/infra/ocibastion/)
- swap memory 설정, OCI CLI, docker, kubectl 설치 등을 아래 글과 같이 수행합니다.
  - 오라클 쿠버네티스 접속 환경 설정하기: [링크](https://juyoung-hong.github.io/infra/ocibastion/)

위 과정을 모두 수행하면 되지만 이미 Bastion 서버를 구성할때 상당부분을 완료하였기에 아래와 같은 순서로 작업을 진행해보겠습니다.

1. CI/CD 전용 Subnet 생성
2. Bastion 서버 종료 및 Custom Image 생성
3. Custom Image를 복제하여 CI/CD VM 생성
4. CI/CD VM에 Jenkins 설치

<br>

## CI/CD 전용 Subnet 생성

<br>

### Route Table 생성

<br>

![create_routetable]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_routetable.jpeg)

먼저 생성해뒀던 VCN의 상세 페이지에가서 Routing 탭으로 이동한 뒤, Create Route Table 버튼을 클릭하여 서브넷을 생성합니다.

![create_routetable2]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_routetable2.jpeg)

CI/CD VM은 private 한 서브넷에 두지만 인터넷에 대한 접속은 필요하므로 Egress Rule에 0.0.0.0/0 으로 NAT Gateway를 사용하는 Rule을 추가하고, OCI의 Container Registry에 접근할 수 있도록 Service Gateway도 추가해줍니다.

![create_routetable3]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_routetable3.jpeg)

최종적으로 위와 같이 route table이 생성됩니다.

<br>

![create_securitylist]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_securitylist.jpeg)

이제 VCN 상세페이지의 Security List 탭에 가서 Security List를 생성해줍니다.

![create_securitylist2]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_securitylist2.jpeg)

![create_subnet]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/create_subnet.jpeg)

## Jenkins 설치

<br>

![run_jenkins]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/run_jenkins.jpeg)

이제 Jenkins 설치를 위해 CI/CD VM에서 아래의 명령어를 입력하여 open jdk 17 버전을 설치해줍니다.

```bash
sudo apt update
sudo apt install openjdk-21-jdk -y
mkdir jenkins
cd jenkins
wget https://updates.jenkins.io/latest/jenkins.war
JENKINS_HOME=jenkins 
nohup java -jar jenkins.war --httpPort=8080 &
```

이후 노트북 단말에서 bastion을 통해서 안전하게 ci/cd 머신에 접근할 수 있도록 아래의 명령어를 통해 8080포트의 터널링을 설정합니다.

cicd_vm은 ~/.ssh/config 경로에 미리 지정한 ssh 접속 관련 설정 파일에 명시되어 있어 그대로 사용하였습니다.

```yaml
Host cicd_vm
  HostName 10.0.x.x
  User ubuntu
  IdentityFile /Users/jyhong/.ssh/prd_oci
  ProxyJump bastion
```

![set_tunnel]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/set_tunnel.jpeg)

```bash
ssh -L 8080:localhost:8080 cicd_vm
```

터널링 연결이 완료된 이후에는 브라우저에서 https://localhost:8080 을 입력하여 jenkins에 접속하고, 최초 접속시에는 jenkins 구동시에 admin password를 입력하여 설치를 마무리합니다.

![jenkins_admin]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/jenkins_admin.jpeg)

![jenkins_install]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/jenkins_install.jpeg)

Install Suggested Packages 클릭 후 조금 기다리면 아래 이미지와 같이 설치를 진행합니다.

![jenkins_install2]({{ juyoung-hong.github.io }}/assets/images/2026-05-05-setcicd/jenkins_install2.jpeg)
